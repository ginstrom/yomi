# Freesound download list (gate G2)

[Index](index.md) · [Step 04](04-sourcing-survey.md) · [Sourcing map](sourcing.md)

**For the user.** The sounds below are the Creative Commons 0 files from freesound.org that the Kenney and OpenGameArt packs do not cover. Originals need a free Freesound login; the site's previews are lossy and are never used.

1. Log in at freesound.org.
2. Open each URL and press **Download** (the original file, not the preview). Each page states "Creative Commons 0".
3. Save each file into `~/.cache/yomi-audio/freesound/` (create the folder) under the **target name** in the last column (`fs_<id>_<slug>.<ext>`, the original extension; just prefix the downloaded name, or rename it).
4. Skip any you like; the rows are ordered by how many W1 cues lean on them, so if you are short of time do the top of the list. Then tell the orchestrator **"done"** (naming any skipped ids) or **"skip all"**. With "skip all", the affected cues fall back to Kenney, OpenGameArt and synthesis (the fallbacks are in the last section of `sourcing.md`) and step 04 says so.
