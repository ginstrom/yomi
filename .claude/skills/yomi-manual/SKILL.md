# The player's manual

Use this after a change to a rule the manual states or a screen it shows: `docs/manual/README.md` is the player's manual, and a change to either updates it and retakes its screenshots.

The manual is one file, `docs/manual/README.md`. Its images live in `docs/manual/images/`.

1. Find what the change touches in the manual: the rule's text, and any screen that now looks different.
2. Update the text. Read it again after the change and check that it still reads true.
3. Retake the screenshots a changed screen needs, and look at every changed image: `screenshots.md`.
4. Commit the images together with the text.
